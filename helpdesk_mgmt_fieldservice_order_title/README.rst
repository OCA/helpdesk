Helpdesk Field Service Order Title
==================================

This module improves the Field Service order list embedded in Helpdesk
tickets.

It displays the computed Field Service order title, keeps the technical
order reference, adds the project and Helpdesk ticket to Field Service
order lists, and makes the location column optional and hidden by
default in the Helpdesk ticket order list.

**Table of contents**

.. contents::
   :local:

Usage
=====

Usage
=====

Open a Helpdesk ticket and open the Service Orders tab.

The embedded list displays the Field Service reference and computed
title. The Location column is hidden by default and can be restored
through the optional columns menu. In the Field Service order list, the
related project and Helpdesk ticket are available as optional columns.
