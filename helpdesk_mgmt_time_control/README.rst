This module adds Time control funcionality in Helpdesk Timesheet module:
start, stop and resume work buttons on tickets and their timesheet
lines, based on ``project_timesheet_time_control``.

**Table of contents**

.. contents::
   :local:

Configuration
=============

Allow Timesheet on the Helpdesk's Team and set a Project on the tickets,
as described in ``helpdesk_mgmt_timesheet``.

Usage
=====

1. In the tickets list, kanban or form view, click on *Start work* to
   start a timer on the ticket, and on *Stop work* to stop it.
2. In the Timesheets tab of a ticket, use *Resume work* or *Stop work*
   on a timesheet line.
