When a helpdesk ticket is created from an auto-generated email (e.g. an
out-of-office reply carrying ``Auto-Submitted: auto-replied`` or
``X-Auto-Response-Suppress: AutoReply``/``All``), the stage welcome
email configured on the ticket stage must **not** be sent back to avoid
an email loop.

This module integrates ``helpdesk_mgmt`` with
``mail_autogenerated_header``: the latter detects such headers on
incoming messages and sets a context key that this module reads in
``_track_template_skip_autoreply`` to suppress the outgoing welcome
email.
