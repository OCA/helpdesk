This module lets you replace the free-text *Description* field of the Helpdesk portal ticket form with a structured, admin-defined set of questions, chosen automatically from the selected category.

Instead of giving customers an empty text box, you stay in control of the questions asked. When a portal category has a form attached, its questions are loaded inline (no page reload, no survey redirect) as soon as the customer picks the category. The submitted answers are rendered as HTML into the ticket description, so agents read a clean, consistent report and notification emails work unchanged.

Categories without a form fall back to the standard free-text description, so the module is safe to install on an existing setup.
