When an auto-generated email (e.g. an out-of-office reply carrying
``Auto-Submitted: auto-replied`` or
``X-Auto-Response-Suppress: AutoReply``/``All``) is received on an
existing helpdesk ticket, the ticket stage must **not** be advanced
automatically to avoid treating bot replies as genuine partner
responses.

This module integrates ``helpdesk_ticket_partner_response`` with
``mail_autogenerated_header`` by overriding
``_skip_ticket_stage_update_from_autoreply`` to detect such headers and
suppress the stage update.
